# Set up the bundled workflows

Every initialized instance already contains this pinned portable bundle. There is no plugin installation step. Read [the native runtime](../../skills/peak/references/raga-runtime/SKILL.md), then assign models to roles: run `/agent-setup` in an ordinary session, or [configure model roles](../../skills/peak/references/peak-setup/SKILL.md) through a candidate revision in an instance session. A null role inherits the session model. Verify available tools with capability_report before choosing a terminal, browser, or formal-verification workflow. Optional integrations require explicit setup. Start with /skill:peak and a goal with observable acceptance criteria.
